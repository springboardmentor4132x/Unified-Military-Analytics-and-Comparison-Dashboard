# Milestone 2: KPI Engineering and Dashboard Preparation  
**Duration:** Weeks 3–4  

This milestone focuses on feature engineering of military KPIs and planning a dashboard prototype for comparative military analysis.

---

## Module 3: KPI Feature Engineering

### Tasks
- Compute the following KPIs:
  - **Power Index Rank Gap**
  - **Assets per Capita**
  - **Budget-to-GDP Ratio**
- Enrich the dataset with metadata:
  - Region
  - Continent
  - Alliance flags (for example: NATO)
- Prepare the data in:
  - Wide format
  - Long format  
  (for dashboard consumption)

### Deliverables
- `military_final.xlsx`
- `generate_kpis.py`

### Evaluation Criteria
- All KPIs are present and correctly calculated
- Dataset loads directly into the dashboard tool without additional transformation

---

## Module 4: Dashboard Planning and Prototyping

### Tasks
- Draft layout sketches or wireframes for:
  - Quick Stats
  - Nation Overview
  - Compare Powers
  - Coalition Builder
- Define:
  - Filters
  - Buttons
  - Navigation logic
- Build a prototype dashboard using sample data

### Deliverables
- Dashboard layout storyboard
- Dashboard application prototype

### Evaluation Criteria
- KPIs and interactions are mapped correctly
- At least one dashboard (Quick Stats or Nation Overview) is operational

---

## Folder Contents
- `generate_kpis.py` – Script for KPI computation and feature engineering  
- `military_final.xlsx` – Final dataset with engineered KPIs  
- Dashboard prototype files and supporting documentation
