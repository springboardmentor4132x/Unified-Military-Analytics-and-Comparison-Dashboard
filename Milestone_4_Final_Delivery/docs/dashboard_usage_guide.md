# Power BI Dashboard Usage Guide

## Opening the Dashboard

1. Install **Power BI Desktop** from Microsoft Store (free)
2. Open `dashboard/global_military_firepower_2025.pbix`
3. Click **Refresh** to load latest data

---

## Dashboard Navigation

Use the **navigation buttons** at the bottom of each page to move between dashboards.

| From | To | Button |
|------|----|--------|
| Quick Stats | Nation Overview | → |
| Nation Overview | Compare Powers | → |
| Compare Powers | Coalition Builder | → |
| Coalition Builder | Quick Stats | → |

---

## Quick Stats Dashboard

**Purpose:** Global military overview

**How to use:**
1. View the **Top 10 Powers** chart
2. Use **Region** slicer to filter by region
3. Use **Continent** slicer to filter by continent
4. Use **Alliance** slicer to filter by NATO, BRICS, etc.

---

## Nation Overview Dashboard

**Purpose:** Deep dive into one country

**How to use:**
1. Select a country from the **dropdown**
2. View all military metrics for that country
3. Check KPI scores and rankings

---

## Compare Powers Dashboard

**Purpose:** Compare two countries

**How to use:**
1. Select **Country 1** from left slicer
2. Select **Country 2** from right slicer
3. Use **multi-select slicer** to filter charts
4. Compare metrics side-by-side

---

## Coalition Builder Dashboard

**Purpose:** Build and analyze military alliances

**How to use:**
1. Select multiple countries from the **country slicer** (Ctrl+click)
2. View **combined totals** (personnel, aircraft, ships, budget)
3. See **contribution chart** showing each country's share
4. Compare your coalition against **USA** in the comparison charts

---

## Tips

- **Ctrl+click** to select multiple items in slicers
- **Hover** over charts for detailed tooltips
- **Right-click** on visuals for more options
- Click **Refresh** if data seems outdated
