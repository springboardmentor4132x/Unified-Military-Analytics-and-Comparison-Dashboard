# Unified Military Analytics and Comparison Dashboard (DV)

## Project Overview
This project focuses on collecting, cleaning, and unifying global military, manpower, and infrastructure data from **GlobalFirepower.com**.  
The final output of Milestone 1 is a **single, clean, Power BI–ready master dataset** at the country level.

---

## Objective (Milestone 1)
- Scrape military and economic indicators from multiple sources
- Clean and standardize country-level data
- Merge all datasets into one master CSV file
- Prepare the dataset for Power BI dashboard development

---

## Data Sources
Data is scraped from publicly available pages on **GlobalFirepower.com**, including:

- Total Population
- Total Military Manpower
- Active Military Personnel
- Defense Budget (USD)
- Fighter Aircraft Count
- Tank Count
- Submarine Count
- Total Serviceable Airports
